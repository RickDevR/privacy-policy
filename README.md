# Privacy Policy for Roblox Local Verifier

## Data Collection & Usage
This extension does not collect, store, or transmit any user data, personal information, or browsing history to external servers. All data processing (such as matching the Roblox profile URL and inserting the cosmetic badge) happens entirely locally on the user's device.

## Data Security
We do not track user activities, passwords, or personal credentials. Because no data is collected, no data is shared with third parties.

## Changes to This Policy
We may update our Privacy Policy from time to time. Any changes will be posted on this page.
